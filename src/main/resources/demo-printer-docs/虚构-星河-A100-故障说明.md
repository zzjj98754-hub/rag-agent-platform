# 虚构星河 A100 故障说明（演示资料）

> 本文件为个人项目演示用虚构资料。请勿将其视为真实维修指引。

## 常见故障

- 卡纸后仍提示卡纸：确认后盖内的传感器区域没有残纸，再断电 30 秒后开机；不要拆卸传感器。
- Wi-Fi 连接失败：星河 A100 必须使用 2.4GHz，并且路由器加密方式应为 WPA2-Personal；不支持企业级 802.1X 网络。
- 文字或图片打印模糊：先做喷头清洁和校准；不要自行拆卸墨盒仓或使用非说明书清洁液。

## 需要停止排查的情况

出现焦味、异常发热、液体进入设备或异响时，应立即拔掉电源，不要再次通电。请在售后申请中说明现象，等待人工处理。
