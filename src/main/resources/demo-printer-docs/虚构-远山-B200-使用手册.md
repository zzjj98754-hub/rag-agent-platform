# 虚构远山 B200 使用手册（演示资料）

> 本文件及“虚构远山 B200”均为个人项目演示用虚构内容，不代表真实厂商服务。

## 卡纸排查

1. 按面板提示打开纸盒盖，先取出纸盒，再从设备上方垂直取出卡纸。
2. 检查纸盒导轨是否贴合纸张边缘，纸张高度不要超过橙色限位线。
3. 重新装回纸盒，关闭纸盒盖并按面板“继续”。远山 B200 不建议从后盖强行抽纸。
4. 测试页仍卡纸时，记录面板错误代码并申请售后，不要拆开侧板。

## 无法连接排查

远山 B200 支持 5GHz Wi-Fi，也支持网线连接。Wi-Fi 失败时在“设置 > 网络 > 重置网络”执行一次，再选择 2.4GHz 或 5GHz 网络；网线连接时应关闭 Wi-Fi 自动切换并打印网络状态页。

## 打印模糊排查

将纸张类型设置为“厚纸”或实际介质，运行“维护 > 对齐打印头”，再打印喷嘴检查页。远山 B200 不建议连续运行清洁程序；喷嘴检查仍缺线时保留检查页并申请售后。
