# 虚构星河 A100 使用手册（演示资料）

> 本文件及“虚构星河 A100”均为个人项目演示用虚构内容，不代表真实厂商服务。

## 卡纸排查

1. 在打印机面板选择“停止”，等待滚筒完全停止。
2. 打开前盖和后盖，沿纸张输出方向缓慢取出整张纸，不要反向猛拉。
3. 取出纸盒重新整理纸张，纸张高度不要超过绿色限位线。
4. 关闭前后盖后重新打印一张测试页。如果同一位置连续卡纸，请停止继续操作并申请售后。

## 无法连接排查

星河 A100 仅支持 2.4GHz Wi-Fi。请在面板进入“网络设置 > Wi-Fi”，选择 2.4GHz 网络并重新输入密码；本型号不支持仅开启 5GHz 的网络。连接成功后打印网络状态页确认 IP 地址。

## 打印模糊排查

在打印设置中把介质类型设为“普通纸”，运行“维护 > 清洁喷头”一次，再打印校准页。星河 A100 使用普通纸时建议质量设为“标准”；连续清洁不超过两次，仍模糊时记录测试页并申请售后。
